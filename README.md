# Rooster Range

A tiny browser shooting-gallery game. Aim the gun at the archery target and click to fire. Hit the gold X ring for a bullseye, and a rooster crows.

**▶ Play it here: https://advikrohith.github.io/rooster-range/**

## Play locally

Open `index.html` in any browser. No install or build step needed.

## How it works

Everything is in `index.html`: the drawing uses an HTML canvas, and the gunshot and rooster sounds are generated with the Web Audio API, so there are no sound files.
